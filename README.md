# Lite Editor (working title)

A lightweight, offline video editor for Windows, built to run on low-end PCs.
Clean-room rebuild of the *features* of a mainstream desktop editor's core editing loop:
no third-party code, assets, icons or branding are used. See `replica/` for the plan.

- `replica/` recon map, feature matrix, architecture, design tokens
- `engine/`  Rust editing engine (std only; drives a bundled FFmpeg)
